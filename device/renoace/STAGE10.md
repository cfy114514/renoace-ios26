## VM 完成与恢复边界

停止点为 `0xfffffff007b33e34`：原始 `arm_vm_init` 完整返回后的第一条指令，位于后续串口、第二次 PE、IOKit 初始化之前。并非内部 `pmap_bootstrap` 的较早返回点。

VM 会将旧探针所在额外 RAM 映射为 RW/NX，并将 TTBR0 替换为无效根；P06 的直接观察器和恒等返回方式因此失效。P07 在已核验的高异常向量页尾 RX NOP 填充区 `0xfffffff007500800` 放入332字节恢复入口，先记录新根，再以真实 MSR/TLBI/DSB/ISB 恢复独立守卫验证的启动根。随后才进入旧观察器、恒等别名和关闭 MMU 的恢复路径。16个高异常入口也经此 RX 区域；16个低异常入口保留物理探针路径。

上下文保留 RW/NX。ABI3 维持原4KiB布局，增加 VM 前后页表观测和 `CNTKCTL_EL1` 保存/恢复；早期超时初始化确实会改写该寄存器。旧 MMU 字段描述恢复后的启动根，新 `vm_*` 字段描述恢复入口捕获的 VM 新根，两者不能混称。

候选构建 `c3ff699044755a00`，Image SHA-256 `358a8102881d6ae15c9c5ade779bf5bf366ec2f4463101303a8e7d9488e95363`。121个私有观测补丁由38个控制字与83个 RX 入口字组成，三个桥内恢复分支单独记录；原始内核和 initrd 成员保持原样。扩展 Image `0x3913000`，完整64KiB栈保留，实际 ABL 保守窗口余量 `0x304000`。

调用方 GPR、系统状态、两个栈、32个 Q 寄存器和 FP 控制恢复通过；CNTKCTL 使用非零初值，验证经过原 VM 改写后精确恢复。独立内存原语190项、严格读取器9份原始模型记录、8项读取器损坏拒绝，以及 P03–P06 历史实机记录回归均通过。集成复核逐条检查121补丁、三个恢复分支、实际 CPIO 与装载边界。窄 A72 模型缺少新路径使用的 LSE 指令；手机实时 CPU 特性及 P06 ISAR0 均确认 atomics/CRC32，不据 A72 不支持推断手机失败。
